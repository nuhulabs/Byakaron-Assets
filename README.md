Public **Byakaron** installers (`.deb`, `.dmg`, `.exe`, Android).

Source and CI live in [nuhulabs/byakaron](https://github.com/nuhulabs/byakaron). Tagged releases here are created by that repository's `release` workflow.

Asset names are **stable** (e.g. `byakaron_amd64.deb`, `Byakaron.dmg`) so

```
https://github.com/nuhulabs/Byakaron-Assets/releases/latest/download/<file>
```

always resolves to the current Latest release. The spell database is baked into the installers and is not published here.
